A single original one-line review of my own Monday, written by a program (`main.ts`, Node 22) to
`$MAKEFUN_OUTPUT_DIR/entry.txt` — 127 characters, one line, nothing else.

> Monday gave my inbox 47 unread emails, a 9 a.m. meeting about a meeting, and a coffee that tasted like it had already given up.

Run it with `node main.ts`. The output is deterministic: the same line every run.
